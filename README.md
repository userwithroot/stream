# 📻 Online Streams of Radio & TV — My M3U Playlist

Коллекция онлайн-трансляций радио- и телеканалов в формате `.m3u` / `.m3u8`. Подходит для воспроизведения в VLC, IPTV-плеерах, Kodi, TiviMate и других приложениях.

## 📋 Описание

Этот репозиторий содержит M3U-плейлист с прямыми ссылками на потоковое вещание радио и телеканалов. Плейлист обновляется вручную по мере появления новых рабочих ссылок.

## 🚀 Как использовать

### 1. Прямая ссылка на плейлист и ТВ-программа

https://raw.githubusercontent.com/userwithroot/stream/refs/heads/main/tv/58.m3u
http://iptvx.one/epg/epg_lite.xml.gz

### 2. В приложении

1. Открой IPTV-плеер (например, VLC, TiviMate, IPTV Smarters).
2. Выбери «Добавить плейлист по URL».
3. Вставь ссылку выше.
4. Наслаждайся!

 ⚠️ Важные замечания

- Некоторые потоки могут быть недоступны в определённых регионах.
- Ссылки могут устаревать — проверяй работоспособность.
- Не добавляй пиратский контент или платные каналы без подписки.
